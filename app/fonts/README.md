# Sour Gummy

`sour-gummy.ttf` is the unmodified upright variable font from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/sourgummy),
originally named `SourGummy[wdth,wght].ttf`.

It is bundled with the site and loaded through `next/font/local` so builds do not
depend on Google Fonts responses. It supports weights 100–900, with the default
width of 100. The accompanying `OFL.txt` contains its SIL Open Font License.
